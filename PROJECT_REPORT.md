Model Design Choices

This project was developed as the peer-reviewed capstone project for the GPU Programming Specialization. The primary objective was to demonstrate the complete workflow of GPU-accelerated deep learning using PyTorch and NVIDIA CUDA while experimentally evaluating the performance benefits of GPU computing through a direct comparison between CPU and NVIDIA GPU training.
To achieve this goal, a compact feed-forward neural network (Multi-Layer Perceptron, MLP) was implemented. The network consists of two hidden layers with 128 and 64 neurons, providing sufficient representational capacity for the MNIST handwritten digit classification task while remaining computationally efficient and easy to understand. This architecture allows the computational performance of CPU and GPU execution to be compared while maintaining a clear and reproducible implementation.
The Adam optimizer was selected because it is widely used in deep learning due to its fast convergence and robust performance with minimal hyperparameter tuning. The Cross-Entropy Loss function was chosen because it is the standard loss function for multi-class classification problems such as handwritten digit recognition.
A batch size of 64 was selected as a practical compromise between computational efficiency, GPU memory utilization, and stable gradient updates. The model was trained for five epochs, which proved sufficient to achieve high classification accuracy while maintaining a relatively short training time.
The experimental results include a direct comparison of CPU and GPU execution, reporting training time, model accuracy, and GPU speedup. While larger neural networks typically achieve greater benefits from GPU acceleration, the results demonstrate that even a compact MLP can benefit from parallel execution on an NVIDIA GPU. Overall, the project provides a clear, reproducible, and well-structured example of GPU-accelerated deep learning and establishes a solid foundation for exploring more advanced neural network architectures in future work.
